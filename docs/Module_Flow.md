# Module Flow

## User Roles

### 1. Admin
- Manage users
- Monitor projects
- View system reports

### 2. Dataset Owner
- Upload datasets
- Create labeling projects
- Assign annotation tasks
- Download labeled datasets

### 3. Annotator
- View assigned tasks
- Perform data labeling
- Submit annotations

### 4. Reviewer
- Verify annotations
- Approve or reject labels
- Provide feedback
