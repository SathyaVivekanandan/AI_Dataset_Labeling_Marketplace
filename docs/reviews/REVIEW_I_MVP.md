# Review-I MVP Demo Script (3–5 minutes)

1. Explain the problem and three roles (owner, annotator, reviewer).
2. Register/sign in and show the JWT-backed workspace.
3. Upload a small sample dataset and show its MySQL-backed record.
4. Create a project linked to the dataset and assign a task to an annotator.
5. Submit one annotation and show it in the annotation list.
6. Show the architecture, ER diagram, class/module diagram, and API contract.
7. State current limitations honestly: baseline AI suggestions are keyword-based; production deployment and per-record authorization must be verified before claiming complete.
